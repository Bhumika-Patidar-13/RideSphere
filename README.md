RideSphere – Vehicle Booking and Driver Management System

Technologies: Java, Spring Boot, Microservices, Spring Cloud Netflix Eureka, OpenFeign, REST APIs.

- Developed a vehicle booking and driver management system using Spring Boot and Microservices Architecture.
- Implemented service discovery using Netflix Eureka Server.
- Used OpenFeign Client for inter-service communication.
- Designed independent microservices for booking, customer, driver, vehicle, payment, and trip management.
